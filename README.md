# Meesho Payment Flexibility Demo

This is a simple prototype showing how a customer can switch from **Cash on Delivery (COD)** to **Google Pay (GPay)** before delivery.  
The goal is to improve user convenience, reduce COD cancellations, and lower cash-handling costs.

---

## 🚀 Features
- Default checkout option shows **COD selected**.
- User can click **Switch to GPay** to simulate online payment.
- Confirmation message updates order status to **Prepaid**.
- Option to **Keep COD** remains available.

---

## 📂 How to Run
1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox).
3. Click through the buttons to see the simulated flow.

---

## 📹 Demo Flow
1. Customer places COD order.  
2. Customer decides to switch → clicks **Switch to GPay**.  
3. Payment gateway processes → order updated to prepaid.  
4. Courier notified → no cash collection needed.
